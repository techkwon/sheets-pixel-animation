Turn Google Sheets into a cute animated pixel-art scene for the "Remember November 2026" internet meme: November 2026 has finally arrived. Draw your own original character (do not copy any existing photo or artwork): a chubby, adorable baby polar bear with a round face and tiny black eyes standing on a snowy ice field at night-blue dusk. Next to the bear is a big wall calendar whose pages flip from SEPTEMBER 2026 to OCTOBER 2026 to NOVEMBER 2026. When NOVEMBER 2026 appears, the bear blushes, waves one paw and does a little happy bounce, then the loop starts again. Snow keeps falling the whole time, with a few stars twinkling and a soft aurora drifting in the sky. Show the month name and year on the calendar as readable blocky pixel letters.

Rules:
- Every pixel's colour must come from a spreadsheet formula in that cell (LET, SIN, MOD, INDEX and so on are fine) that depends on a single frame counter cell. Changing the frame counter must re-render the whole picture inside the spreadsheet; Apps Script must not paint pixels itself.
- Use Apps Script only to (1) build the sheet: shrink rows and columns so each cell is a small square pixel, write the formulas, add conditional formatting (or another native method) that maps the formula values to colours, and (2) advance the frame counter in a loop so it animates.
- Make the bear big and cute enough to read clearly, but keep it fast enough to run in a normal Google Sheets file: choose a grid size and colour palette that recalculates quickly, and say what frame rate to expect. One full loop (calendar flips + wave) should take about 15 seconds at that frame rate.
- Deliver one file named Code.gs in the current directory. Start it with the line /** @OnlyCurrentDoc */. Include setup() to build everything in the active spreadsheet, play() to animate for about 60 seconds, stop(), an onOpen() menu, and a short comment block explaining how to paste it into Extensions > Apps Script and run it. No external libraries or network requests.
Do it in one go, do not ask questions.
