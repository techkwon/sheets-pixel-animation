갤러리

실제 구글 시트에서 60초 동안 돌린 화면을 녹화했습니다. 빨리 감기 없이 실제 갱신 속도 그대로입니다. 시트 보기는 보기 전용이라 멈춘 그림이고, 움직이게 하려면 사본 만들기 후 메뉴에서 Play를 누르세요.

어떻게 움직이나

스크립트는 붓이 아니라 시계입니다.

1. 프레임 칸B1 같은 칸 하나에 프레임 번호가 들어 있습니다.
2. 픽셀 수식수천 개의 셀이 =LET(f,$B$1, … SIN · MOD · INDEX …)로 자기 색 번호를 계산합니다.
3. 조건부 서식색 번호 16~24개를 배경색으로 바꿉니다.
4. play()Apps Script는 프레임 번호를 1씩 올리고 화면을 새로 고칠 뿐입니다.

스킬로 직접 만들기

주제 한 줄을 주면 프롬프트 작성 → Hydrogen이 Code.gs 작성 → clasp로 새 시트 만들기까지 자동으로 합니다.

git clone https://github.com/techkwon/sheets-pixel-animation.git
cd sheets-pixel-animation
./install.sh            # Antigravity CLI (agy)
./install.sh --claude   # Claude Code에도 설치
agy -p "구글 시트 애니메이션 만들어줘: 벚꽃 날리는 운동장에서 강아지가 공을 쫓는 장면" --model gemini-4-hydrogen-high

준비물: Antigravity CLI(Gemini 4 Hydrogen), Node.js, Python 3, clasp(npm i -g @google/clasp → clasp login, Apps Script API 켜기). 녹화 자동화는 선택(ego-lite, ffmpeg). 설치 없이 해 보려면 예제의 Code.gs를 새 시트의 확장 프로그램 → Apps Script에 붙여 넣고 setup을 실행하세요.
